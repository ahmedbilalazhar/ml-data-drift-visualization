% \textbf{Assis and Souza: unsupervised windowing.} ADWIN-U adapts ADWIN's variable-window
% cut search to unlabeled streams by monitoring incremental descriptive statistics
% (skewness, kurtosis) instead of error rate. Evaluation covers ten real USP repository
% streams (Electricity 44,312 test rows; GasSensor; Insects Abrupt/Gradual/Incremental;
% LADPU; Outdoor; Rialto; StarLightCurves; Yoga) with a Random Forest base learner and
% $\delta=0.002$, against Blind, Persistent, KS-TEST, and supervised ADWIN (error/output)
% baselines under rolling holdout validation \cite{assisu}. The paper also proposes BAR,
% the harmonic mean of model accuracy and label frugality, to stop always-retrain
% strategies from winning on accuracy alone. \emph{Author-stated limits:} statistic choice
% trades compute against sensitivity; adaptive windows still need calibration; BAR weights
% accuracy first. \emph{Our assessment:} the USP suite overlaps our Electricity/Insects
% context, which strengthens external validity, but feature-level attribution and any
% operator display are absent, and threshold/$\delta$ transfer across streams is untested.
% Skewness/kurtosis summaries can miss dependence-only change, and rolling-holdout
% coupling of detector and model makes isolated detector delay hard to read off.
