# Day 1 package

This is the complete Day 1 research-improvement edition. `REPORT.tex`, `REFERENCES.bib`, and `REPORT.pdf` are the editable report source and compiled output. `figures/` holds the figure assets and `qa/` holds rendered PDF pages inspected during review. `FINDINGS.md`, `DEMO_GUIDE.md`, `CONTINUE.md`, and `CHECKPOINT.md` document interpretation and continuation.

`Core_Research_Complete.zip` is the preserved, previously validated project package containing the implementation, locked protocols/configuration, results, historical reports, visualization, and receipts. The Day 1 report and audit are layered beside it; the core archive is not modified.

From the project root, compile the report with:

```powershell
tectonic docs/phase3/research_improvement_day1/REPORT.tex --outdir docs/phase3/research_improvement_day1 --keep-logs
```
