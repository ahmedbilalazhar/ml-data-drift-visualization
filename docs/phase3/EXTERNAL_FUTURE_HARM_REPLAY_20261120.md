# External future-harm replay

The synthetic forecast study found that the unlabeled monitor's performance depended on the shift mechanism. This follow-up measures how usable three simple prospective signals are on the existing ordered ELEC2, NOAA and UCI224 streams. It reuses previously studied outcomes, so it is a retrospective replay of a prospective decision rule.

## Locked design

- Use the published frozen classifier and historical reference accuracy for each stream. The first UCI224 acquisition cohort supplied historical fitting and reference data. Its reference row is excluded from monitoring. Keep the ELEC2 partial final cohort. NOAA uses the complete published evaluation cohorts.
- Forecast mean accuracy over the next five cohorts. Also report one-cohort horizons as a secondary check. Weight cohorts equally within each horizon, and score every valid origin equally within its stream. Advance in acquisition order and use cohort steps as the clock. A step has different real durations and row counts across streams.
- Simulate label delays of 0, 2 and 5 cohorts. A monitoring outcome from cohort j can be used at origin t only if j + delay < t. Compare historical reference accuracy, current unlabeled calibrated accuracy estimate, latest released cohort accuracy, and mean of the last three released cohorts (or all available when fewer than three). The last two fall back to historical reference accuracy when zero labels are available. There is no fit or tuning to external outcomes.
- Measure absolute error, signed bias and number of origins with released outcomes. As a descriptive decision check, flag predicted five-point harm when forecast accuracy is more than five percentage points below the historical reference. Tabulate false positives and false negatives against the same rule applied to realized future mean accuracy. These are point forecast decisions, without probability calibration.
- Report both all valid origins and the common subset where at least one result was released even at the longest delay. An empty common subset is an availability result. Report each stream separately. Overlapping future horizons are dependent, and there are only three ordered streams. No pooled inferential interval or general transfer claim is supported.
- Keep forecasts separate from future targets. Verify that perturbing all unreleased outcomes, including the current cohort, leaves every forecast and release count unchanged. Record source and output hashes, use a fresh output directory and produce a same-environment comparison receipt.
