# Day 3 final research package

This package preserves the validated Day 1 and Day 2 packages and adds the final external-evaluation report and the exploratory sensitivity analysis. The corrected primary run, superseded initial split run, data source, figures, implementation, class metrics, cohort metrics, protocols, receipts, and hash inventory are included through the nested Day 2 package. Final archive: `IDM_Viz_Phase3_Day3_Final_Research_Improvement_v1.4_Validated.zip`.

Rebuild the report from the project root:

```powershell
tectonic docs/phase3/research_improvement_day3/REPORT.tex --outdir docs/phase3/research_improvement_day3 --keep-logs
```

Reproduce the external study and Day 3 sensitivity with the commands in the Day 2 package README. This is one external dataset with nine unequal evaluation cohorts; it is not a collection of independent replications.
