# Heuristic walkthrough checklist (replaces user study; roadmap Sec. 10.2)
# Reviewer: supervisor or experienced peer. Time: ~30-45 min. No participants.

For one figure per case (S1 harmless, S2 gradual, S6 joint, S7 conditional):
- [ ] Shared time axis: alert windows align with the F1 windows they claim about?
- [ ] Threshold shown as labelled ratio/line, never "drift probability"?
- [ ] Missing/delayed F1 shown as gap + "labels delayed" tag, never as zero?
- [ ] Measured vs inferred features visually distinct (E0: all measured)?
- [ ] S1: harmless-shift panel does NOT recommend retraining?
- [ ] S7: silent-detector panel does NOT say "no problem" (says unknown/request labels)?
- [ ] Small-group/predicted-label warnings carry support counts?
- [ ] Colorblind-safe + text/shape redundancy, units + window ids in captions?
Record: date, reviewer, figure IDs, pass/fail per item, fixes required.
